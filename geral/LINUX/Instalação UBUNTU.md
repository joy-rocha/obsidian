# Instalação RUFUS 
clique no link para instalar: [`rufus-4.15.exe`](https://github.com/pbatard/rufus/releases/download/v4.15/rufus-4.15.exe)
- serve para migrar o SO para pendrive

# Configuração (RUFUS)

abra o executável do rufus -> seleção de boot (selecionar) -> escolhe o linux -> esquema de partição (GPT) -> iniciar -> iniciar no modo ISO -> OK ->espera terminar ->FECHAR

 - agora vc tem um pendrive bootável, que carrega um sistema operacional pronto pra ser instalado.

# Dual Boot
desligue e ligue o PC com o pendrive bootável conectado -> aperte F2 ou Del para abrir a tela de Boot -> escolha "Try or Isntall Ubuntu" -> va configurando as telas -> tipo de instalação escolha "Instalar o Ubunto ao lado do windows Boot Manager " -> instalar agora
