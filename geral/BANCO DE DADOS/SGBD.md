**Sistema Gerenciador de Banco de Dados**
	É a aplicação responsável pelo controle e manipulação dos dados de um BD

**CARACTERÍSTICAS**
- permite acesso concorrente ás bases de dados
- realiza o gerenciamento de transações permite criar e aplicar regras para a segurança e integridade dos dados
- evita redundância e inconsistência
- Possui controle de centralização *Lógica*. O que garante compartilhamento de dados, segurança, integridade e a eliminação de redundância e inconsistência

**EX de SGBD's :**
Oracle, Mongo DB, Maria DB, MySql, IBM ...

### A **independência de dados** 
É a capacidade de modificar a estrutura de um banco de dados em um determinado nível sem precisar alterar os níveis superiores ou os programas de aplicação que o utilizam. Garante a separação dos dados entre os programas de aplicações e os dados armazenados. Permitindo que mudanças em um nível não afetem obrigatoriamente o outro.

### Controle centralizado

>**centralização lógica**.
	Ele literalmente "finge" para o usuário, para o programador e para os aplicativos que todos os dados estão juntos em uma única tabela ou em um único lugar unificado.
> **centralização física**
	É de fato o armazenamento de todos os dados em um local único
