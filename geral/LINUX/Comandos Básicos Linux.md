**ls** -> comando de listagem
**ls -a** -> comando de listagem que mostra também arquivos ocultos
**clear** -> comando para limpeza do terminal
**cd** -> navega nas pastas, entra
**cd** **..** -> navega para fora da pasta
**mkdir** "nome" -> cria diretório (pasta)
**tab** -> autocompleta os comandos
**pwd** -> retorna o caminho atual
**touch** nome.txt -> cria um arquivo de texto
**mv** nome_antigo nome_novo -> renomeia nome dos arquivos
**find . -name** nome_do_arq -> busca os arquivos com o nome especificado
