**Instalar o Java (JRE)**

Abra o terminal (`Ctrl + Alt + T`) e instale o Java Runtime Environment:

Bash:
```
sudo apt update && sudo apt install default-jre -y
```

**O que é esse Java na prática:**

- **Software Livre e Oficial:** O OpenJDK é a versão aberta e comunitária do Java, desenvolvida e mantida pela comunidade em conjunto com grandes empresas como Oracle, Red Hat e Microsoft.
    
- **Apenas para Execução (JRE):** A sigla JRE significa _Java Runtime Environment_. É o "motor" necessário para abrir e rodar programas já prontos (os arquivos `.jar`, como o brModelo), sem carregar o sistema com ferramentas pesadas de desenvolvimento.
    
- **Diferença para o Java da Oracle:** Na prática e no funcionamento, nenhuma. A diferença é apenas de licença: a Oracle possui uma versão comercial própria com restrições de uso, enquanto o OpenJDK é 100% gratuito e o padrão nativo do Ubuntu.
    

Pode usar tranquilamente, é a versão mais segura, leve e recomendada para o seu sistema!
