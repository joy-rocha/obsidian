$->$ Representação formal dos níveis de modelagem

**NÍVEIS DE MODELAGEM:**
-  CONCEITUAL: Os dados têm a representação fiel da **realidade observada**
-  LÓGICO: Os dados têm a representação de acordo com a **tecnologia utilizada**
-  FÍSICO: Os dados têm a representação de acordo com a **estrutura de armazenamento**
